# 入梦师 Demo 自测清单

这份清单记录原型阶段的人工功能验证范围。状态仅代表当前开发过程中的自测情况，不等同于完整测试报告。

| 模块 | 测试点 | 预期结果 | 当前状态 |
| --- | --- | --- | --- |
| 基础移动 | 左右移动与方向切换 | 输入响应正确，速度与朝向同步 | 已进行人工验证 |
| 跳跃 | 跳跃预输入与土狼时间 | 离开平台短时间内仍可跳跃，落地前输入可在落地后触发 | 已进行人工验证 |
| 空中状态 | 二段跳次数限制 | 未落地时不能重复无限跳跃 | 已修复并复测 |
| 碰撞检测 | 角色自身碰撞体过滤 | 自身碰撞体不会被识别为地面 | 已修复并复测 |
| 墙面动作 | 墙面滑行与蹬墙跳 | 贴墙、离墙和蹬墙状态切换连续 | 已进行人工验证 |
| 剧情流程 | 对话、选项与跳转 | 节点按配置进入下一节点 | 已进行流程验证 |
| 条件分支 | 标记与条件跳转 | 不同标记进入对应分支 | 已进行流程验证 |
| 场景衔接 | 剧情中心进入玩法关卡 | 解锁与完成状态能够正确传递 | 已进行流程验证 |
| 多槽位存档 | 新建、选择与覆盖存档 | 不同槽位数据相互独立 | 待持续回归 |
| 异常存档 | 当前文件损坏或读取失败 | 尝试读取备份；失败时安全返回 | 已实现，待补充系统化异常注入 |
| 版本迁移 | 旧存档缺少新增字段 | 载入时补全默认值并更新格式版本 | 已实现，待补充多版本样本 |
| 输入配置 | 重复按键绑定 | 能发现并提示按键冲突 | 已实现，待扩充场景覆盖 |
